## What I Work On

I specialize in the intersection of **API security testing** and **regulatory compliance** — specifically how regulations like GDPR, HIPAA, and the EU AI Act translate into concrete technical security controls for modern API-driven systems.

My domain covers three tightly connected areas:

- **API & Web Application Security** — vulnerability assessment, authentication flaws, authorization testing, injection attacks
- **AI / LLM Security** — threat modeling for LLM-powered systems, prompt injection, OWASP LLM Top 10, EU AI Act compliance
- **Data Privacy & GRC** — GDPR technical implementation, HIPAA Technical Safeguards, NIST AI RMF, risk assessment, control mapping

Industries I focus on: **Financial Services** and **Healthcare** — the two sectors with the highest regulatory burden and the most complex API security requirements.
